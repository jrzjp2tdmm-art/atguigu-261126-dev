# atguigu-261126-dev

用于整理尚硅谷 Python 课程资料。课程内容按天存放，课件、练习和考试资料按用途分类。

## 目录结构

```text
.
├── courseware/      # 课程课件
├── exercises/       # 课后练习
├── day01/
│   ├── day01.md
│   ├── Typora安装和使用.md
│   ├── demo1/
│   └── demo2/
├── day02/
│   ├── demo1/
│   ├── demo2/
│   └── 进制.xls
└── exams/
    ├── day01/
    ├── day02/
    └── ...
```

计算机英语词汇表与 Python 课程资料一并放在 `courseware/`。后续课程按 `day03`、`day04` 等目录依次添加。视频保留在本机对应课程日的 `videos/` 目录中，不纳入仓库。考试资料直接按 `exams/dayNN/` 存放；题目或答案缺失时只保留现有文件。

## 运行示例

需要安装 Python 3。在仓库根目录打开终端后，可以运行示例，例如：

```bash
python3 'day01/demo2/test_1.py'
```
