# atguigu-261126-dev

用于整理和保存尚硅谷课程学习资料的仓库，按课程天数分目录。

## 目录结构

```text
.
├── README.MD
└── day01/
    ├── day01-笔记/
    └── day01-代码/
        ├── demo1/
        └── demo2/
```

后续课程按 `day02`、`day03` 等目录依次添加。笔记和示例代码保留课程原有目录结构；体积较大的课程视频不纳入仓库。

## 运行示例

需要安装 Python 3。在仓库根目录打开终端后，可以运行示例，例如：

```bash
python3 'day01/day01-代码/demo2/test_1.py'
```
